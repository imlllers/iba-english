# Дизайн

Оформление кабинета повторяет дизайн-систему Sessionary. Акцент `#164AA1`, белый `#FEFEFE`, мягкий синий `#DCE4F1`, тёмный `#1C1D1E`. Шрифт – Geologica. Слева синяя панель 250px с белыми пунктами меню, справа светлый лист со скруглением 16px.

Кнопки и поля: высота 42px, скругление 6px. Основная кнопка залита primary, вторая – обводка, тихая – только текст. Наведение основной – primary на 70%, нажатие – `#1C1D1E`. Кнопки-иконки круглые 42×42. Фокус поля – граница primary.

Заголовок страницы в кабинете – 40px / 52px. Основной текст – 16px / 26px. Расстояния только из шкалы 4, 8, 12, 16, 24, 32, 40, 48, 56, 64, 72, 80. Сетка рабочей области – 12 колонок, gutter 24px. Поле публичной страницы – 90px.

Логотип IBA Institute лежит в `frontend/public/logo.png`. На синей панели он стоит на белой плашке, чтобы синий знак оставался читаемым.

```css
:root {
  --color-white: #FEFEFE;
  --color-primary: #164AA1;
  --color-primary-soft: #DCE4F1;
  --color-dark: #1C1D1E;
  --color-error: #E03131;
  --color-success: #2F9E44;
  --color-warning: #F08C00;
}
```

## Кабинеты

Преподаватель: синяя панель слева – «Мои тесты», «Материалы», «Результаты», «Настройки». Выход – внизу синей панели.

Администратор: та же система, пункты «Преподаватели», «Тесты», «Журнал действий», «Настройки».

Конструктор на широком экране: секции слева, контент в центре, настройки типа справа. Фон боковых панелей доходит до краёв экрана, содержимое внутри идёт по сетке. Справа панель сворачивается. На среднем экране она выдвижная, на мобильном настройки открываются отдельно.

Прохождение теста идёт без административной навигации: шапка с логотипом, названием, таймером и состоянием сохранения, навигатор по заданиям сгруппирован по секциям. Таймер становится красным за 5 минут до конца.

Общие токены и базовая типографика живут в `frontend/src/styles/`. Стили страниц и компонентов – рядом с ними, не в одном общем файле.
