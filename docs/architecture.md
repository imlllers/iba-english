# Архитектура

Один развёрнутый экземпляр для нескольких преподавателей. Backend – модульный монолит на Spring Boot. Frontend – одно React-приложение с кабинетами после входа и отдельным публичным прохождением.

## Backend

Пакеты `com.iba.testing`:

| Пакет | Что делает |
| --- | --- |
| `auth`, `security`, `user` | вход, сессия, CSRF, профиль, роли и статус учётки |
| `test`, `section` | тесты, секции, черновик, публикация версии, ссылка |
| `question` | 41 тип заданий и 16 движков проверки |
| `preset` | стартовые структуры IELTS, TOEFL, TOEIC |
| `attempt` | публичное прохождение, таймеры, сохранение ответов, запись голоса |
| `result` | результаты, ручная проверка |
| `media` | загрузка и выдача файлов |
| `export` | экспорт и импорт zip одного теста |
| `admin`, `platform`, `audit` | кабинет администратора, настройки, журнал действий |
| `common`, `config` | формат ошибок, health, CORS, конфигурация |

## Frontend

`src/app` – маршруты, шапка, меню, проверка роли. `src/pages` – страницы. `src/features` – конструктор, типы заданий, прохождение, результаты, админка. `src/entities` – типы и API-модули сущностей. `src/shared` – клиент API, общие компоненты и хуки. `src/styles` – токены и сетка.

Страницы загружаются лениво. Данные сервера идут через TanStack Query, формы – через React Hook Form и Zod. Контент заданий редактируется в Tiptap и хранится как JSON.

## Доступ

Проверки владельца и роли выполняются на backend.

- Преподаватель видит и меняет только свои тесты, попытки, экспорт и материалы. Чужой тест по id не открывается.
- Учётная запись со статусом `BLOCKED` не выполняет защищённые операции.
- Администратор работает в отдельной зоне. Ответы участников ему не отдаются.
- Публичная ссылка открывает только опубликованную версию теста и действует ограниченное время. Срок задаётся в настройках платформы, по умолчанию 12 часов. Ссылку можно сменить или отозвать.
- Попытка идентифицируется секретным токеном, в базе хранится его хеш.
- Отдельного кабинета студента нет.

## Конструктор

Секции и задания сохраняются автоматически вскоре после правки. Если сохранить не удалось, черновик задания остаётся в `localStorage` и его можно восстановить. Перед публикацией сервер проверяет каждое задание; при ошибке конструктор открывает проблемное задание.

## Публикация и прохождение

Черновик редактируется. Публикация фиксирует версию. Начатые попытки остаются на той версии, с которой начались. Публичный API не отдаёт правильные ответы.

Ответы участника сохраняются по мере ввода. Токен попытки лежит в `localStorage`, после перезагрузки попытка продолжается. Время теста и секций проверяет сервер: просроченный ответ не принимается, отправка доступна всегда. Повторная отправка не пересчитывает попытку.

Результат показывается как «Баллы: x из y», без пересчёта в официальные шкалы экзаменов.
